# Axial crush of thin-walled steel tubes: published experiments and closed-form theory

Compiled 2026-10-21, 17:20–17:40 +02:00 (Europe/Zagreb) for Forge P1a. Read-only web research.

- Data: [`data/crush-experiments.csv`](../data/crush-experiments.csv) holds 48 tests, the raw published values only.
- Theory check: [`data/crush-theory-check.csv`](../data/crush-theory-check.csv), generated by [`scripts/crush_theory.py`](../scripts/crush_theory.py).
- Graphs: [`scripts/crush_plots.py`](../scripts/crush_plots.py) writes them to `forge/docs/img/`.

## Rules used
- Every number was read in the cited document this session. Nothing is estimated or invented. If a value could not be confirmed, its cell is empty.
- `value_method` in the CSV says how we got each measured value:
  - **table**: read from a table in the paper.
  - **text**: read from the paper's running text.
  - **digitized**: read off a figure. Only the P1a force–displacement curve is digitized, by the P1a worker.
  - **computed**: derived by us from published numbers with a published formula. This covers SEA, crush-force efficiency and all theory values.
- The A&J 1984 and 1986 papers are Elsevier copyright. We store only the numbers, as facts with citations. We do not store their text, tables or figures in this repo. Park et al. 2022 is CC BY 4.0. Its PDF and extracts stay local as well (gitignored), and we use only the numbers.
- The A&J text was read from the authors' full-text PDFs as OCR text (academia.edu). For every dynamic row we kept, we re-checked the energy/δf = P_m^d arithmetic. Every static square row reproduces the paper's own theory column exactly (see the theory check below). That makes OCR digit errors unlikely, but not impossible.

## Closed-form theory used (square tubes: c = side, h = wall thickness, M_0 = σ_0 h²/4)

| Name | Formula | Source |
|---|---|---|
| Superfolding, symmetric | P_m/M_0 = 38.12 (c/h)^(1/3), i.e. P_m ≈ 9.53 σ_0 h^(5/3) c^(1/3) | Wierzbicki & Abramowicz 1983; A&J 1984 eq. 3 |
| Symmetric, with effective crushing distance δ_e/2H = 0.73 | P_m/M_0 = 52.22 (c/h)^(1/3), i.e. P_m ≈ 13.06 σ_0 h^(5/3) c^(1/3) | A&J 1984 eq. 33 = A&J 1986 eq. 19 |
| Asymmetric mixed mode B (δ_e/2H = 0.77) | P_m/M_0 = 45.90 (c/h)^(1/3) + 1.75 (c/h)^(2/3) + 1.02 | A&J 1986 eq. 22 (the 1984 eq. 35 has slightly different coefficients) |
| Extensional (δ_e/2H = 0.77) | P_m/M_0 = 32.64 (c/h)^(1/2) + 8.16 | A&J 1986 eq. 23 |
| Circular, axisymmetric (modified Alexander) | P_m/M_0 = [25.23 (2R/h)^(1/2) + 15.09] / [0.86 − 0.568 (h/2R)^(1/2)] | A&J 1986 eq. 46 |
| Cowper–Symonds rate factor | P_m^d / P_m = 1 + (ε̇/D)^(1/p), with D = 6844 s⁻¹ and p = 3.91 (fit to the ultimate stress of low-carbon steel, Campbell & Cooper data). Sensitivity case: D = 802 s⁻¹, p = 3.585 | A&J 1984 eq. 38–39; A&J 1986 eq. 25–26 |
| Mean strain rate | ε̇ = 0.33 V/c (symmetric), 0.39 V/c (mode B), 0.25 V/c (extensional). Circular: ε̇ = 0.25 V / {R[0.86 − 0.568 (h/2R)^(1/2)]} | A&J 1986 eq. 30–31, 53 (assumes v_m ≈ V/2) |
| Flow stress | σ_0 = σ_u, from a tensile test at about 2×10⁻⁴ s⁻¹ (1984) or about 5×10⁻⁴ s⁻¹ (1986) | A&J 1984 §4.8; A&J 1986 §5.1 |

Note: the classic Cowper–Symonds constants for mild steel are D = 40.4 s⁻¹, q = 5. They are fitted near the yield strain. A&J say these constants do not suit the large strains (about 11–13 %) in a fold, so we do not use them for the crush check. See also research/materials.md §3.8.

## Derived quantities (computed)
- **SEA** (energy per crushed mass) = P_m / (ρ A), with A = 4ch for square and πch for circular (c = 2R). The crush length cancels out. We use ρ = 7850 kg/m³ (nominal carbon steel) wherever the paper gives none, which is every source except Aljawi (7830 kg/m³, the paper's FE input).
- **Crush-force efficiency** CFE = P_m / P_peak. Only Park 2022 reports a peak. CFE ranges from 0.26 (US-1) to 0.43 (US-4).
- **Stroke ratio** = δ_f / L, where δ_f is reported (A&J dynamic tests, Aljawi).

## Theory check: results
Prediction = the mode-matched A&J formula with σ_0 = σ_u, times the Cowper–Symonds factor (D = 6844 s⁻¹, p = 3.91). For quasi-static tests that factor is about 1.01. Error = (theory − measured)/measured.

| Group | n | Static formula only: mean error | With Cowper–Symonds: mean error (mean abs) |
|---|---|---|---|
| Park 2022 (A500, quasi-static) | 6 | +23.1 % | +24.5 % (24.5 %) |
| A&J 1984 static | 6 | −3.6 % | −2.5 % (4.5 %) |
| A&J 1984 dynamic, 6.2–10.4 m/s | 13 | −29.0 % | −7.2 % (7.5 %) |
| A&J 1986 static (square and circular) | 12 | −4.9 % | −3.5 % (7.5 %) |
| A&J 1986 dynamic, 4.6–10.9 m/s | 10 | −26.8 % | −3.1 % (17.5 %) |
| Aljawi 2002 (σ_0 = σ_y = 280 MPa; σ_u not reported) | 1 | +0.7 % | +5.2 % |
| **All 48** | 48 | | −0.6 % (11.3 %); 27 of 48 within ±10 % |

Cross-checks:
- For the 7 static square tubes in A&J 1986 Table 3, our computed theory equals the paper's own P̄_m column to 4 significant figures.
- For the 5 circular tubes, our eq. 46 values are 0.4–0.7 % above the paper's column (a small rounding or coefficient difference we could not resolve).
- For Aljawi, eq. 33 with 280 MPa gives 22.33 kN. The paper states 22.333 kN.

What this shows:
1. The A&J closed form with σ_0 = σ_u predicts the original Liverpool static tests within about ±10 % (a few extensional and short tubes reach −18 %).
2. Dynamic tests are under-predicted by about 27–29 % if strain rate is ignored. The Cowper–Symonds correction closes most of that gap. The 1986 type D tubes are over-predicted by about 22–25 % with the correction; A&J themselves note these tubes "appear almost strain rate insensitive". The D = 802 s⁻¹, p = 3.585 alternative raises the dynamic predictions by about 14 % on average (mean error +9 %, mean abs 14.5 %). The rate correction is the least certain part of the theory, as A&J themselves state.
3. For the Park/Jung A500 tubes, the same formula over-predicts by 10–32 %. We have **not** established why. Candidate reasons, all untested:
   - P_m defined over the maximum deformation, including the initial peak and the end of crushing.
   - σ_T in Park Table 2 may not be the same quantity as A&J's σ_u.
   - Cold-formed hollow sections with rounded corners.
   - Long specimens (L/b = 4.5–6).
   - A different flow-stress definition.

   This matters for P1a: P1a is judged against the measured US-2 curve and Table 4 values, not against this formula.
4. Specimen T7 (A&J 1984, δ_f = 23.3 mm, under one full lobe) shows that short crush distances inflate the mean force, as the initial peak dominates.

## P1a target (from this dataset)
Park 2022 US-2 is a square 100 mm × 2.8 mm × 450 mm tube in ASTM A500 Grade A. Its properties: σ_y = 310.8 MPa, σ_T = 363.3 MPa, E = 205.8 GPa, elongation 35.4 %. It was crushed at 0.05 mm/s. Measured peak P_u = 337.1 kN, mean P_m = 101.0 kN (Table 4); computed SEA ≈ 11.5 kJ/kg. Park's own ABAQUS FE gave P_m = 83.7 kN (free) and 87.3 kN (fixed boundary); this is an external FE reference, not experiment.
