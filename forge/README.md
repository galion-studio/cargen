# forge/ — truth-layer crash orchestration (Rust)

This folder is the Rust workspace for Forge's truth layer. Project overview, physics principles, validation data and licences: see the [top-level README](../README.md).

## What is here
| Path | Contents |
|---|---|
| `crates/forge-crash` | Deck generation for OpenCourant (`.rad` starter/engine files), tube mesh, parameters, external solver launch (`Compute` trait, CPU backend), time-history parsing, metrics, ISO/TS 18571 scoring, report |
| `data/p1a/` | P1a experimental reference: Park et al. 2022 specimen US-2 force–displacement curve, digitized from Fig. 3 (CC BY 4.0) |
| `scripts/` | Digitization script for that curve |
| `docs/physics/` | Physics reports (P1a report: `p1a-tube-crush.md`, written when the run completes) |
| `docs/img/` | Figures used in the READMEs (generated by `../scripts/crush_plots.py`) |

OpenCourant (AGPL-3.0) is **not** part of this repository. It is downloaded separately and run unmodified as an external program. Solver output (`runs/`) and build output (`target/`) are not tracked.

## P1a: square steel tube axial crush
Target: Park, Cho & Kim 2022, *Materials* 15:2107 ([doi:10.3390/ma15062107](https://doi.org/10.3390/ma15062107)), specimen US-2.
- Tube: 100 × 100 × 2.8 mm, 450 mm long, ASTM A500 Grade A.
- Material: σ_y = 310.8 MPa, σ_T = 363.3 MPa.
- Loading: crushed quasi-statically at 0.05 mm/s.
- Measured results: peak 337.1 kN, mean 101.0 kN.

Status: **in progress**. No simulated result is published yet.

<p align="center"><img src="docs/img/p1a-force-energy.png" alt="P1a force and energy vs displacement (simulation pending)" width="760"></p>

### Running
Generate the P1a input deck for a given shell element size in mm (default 5):
```
cargo run --release --bin forge-p1a -- 5
```
This writes `TUBE_0000.rad` (starter) and `TUBE_0001.rad` (engine) to the current directory. Full run, post-processing and validation instructions will be added with the P1a report in `docs/physics/p1a-tube-crush.md`.
